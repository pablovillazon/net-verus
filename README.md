# Verus Companies

Company submission API (.NET 10) with an Angular frontend.

## Prerequisites
- .NET 10 SDK
- Node.js 20+ and npm (frontend, added in a later stage)

## Run the backend
```bash
dotnet run --project src/Verus.Companies.Api
```
- http://localhost:5000
- https://localhost:7000
- Health check: `GET /health`

## Run the tests
```bash
dotnet test
```
